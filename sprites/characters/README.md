# Character library

Each class owns variants/, each variant owns animations/, and each animation owns versioned sheets and metadata.
Starter class folders are organizational slots, not completed assets.
Copy the elf-wizard example structure for any other class or variant.
Use class names that describe the actual character; add classes freely without renaming existing assets.

Keep references in ../../sources/, review records in ../../reviews/, and decisions in ../../approvals/.
See [production requirements](../PRODUCTION.md).
